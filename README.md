## 🇧🇷 Português

### 📝 Sobre o Projeto
O **PokéWiki & Team Builder** é uma aplicação web interativa desenvolvida para treinadores Pokémon consultarem dados enciclopédicos e construírem times competitivos ou casuais. O projeto integra dados diretamente da PokéAPI, cobrindo todos os Pokémon registrados até a **9ª Geração (Paldea)**.

### ✨ Funcionalidades Principais
* **Enciclopédia Completa (Gerações 1 a 9):** Navegação organizada por abas de geração e visualização em cards de todos os 1025+ Pokémon.
* **Sistema de Busca e Filtros:** Pesquisa em tempo real por nome ou número da PokéDex, combinada com filtros avançados por Tipo e Geração.
* **Modal de Detalhes (Estilo Wikipédia):** Visualização completa de estatísticas base, tipos, biologia, altura, peso e habilidades de cada Pokémon.
* **Montador de Time (Team Builder):** Seleção de até 6 Pokémon para a criação de equipes personalizadas com persistência em `localStorage`.
* **Análise Tática e Vulnerabilidades:**
  * **Gráfico de Vulnerabilidades Defensivas:** Mapeia fraquezas, resistências e imunidades do time contra os 18 tipos existentes.
  * **Cobertura Ofensiva (STAB):** Identifica quais tipos o time consegue atingir com dano super efetivo.
  * **Diagnóstico Estratégico:** Gera alertas e sugestões automáticas sobre pontos fracos e equilíbrio do time.
* **Customização de Temas:** Alternância dinâmica de temas visuais baseados em Pokémon (*Amarelo Pikachu*, *Escuro Umbreon*, *Vermelho Rotom*).

### 🛠️ Tecnologias Utilizadas
* HTML5 / CSS3 (Variáveis CSS e Grid Layout)
* JavaScript Vanilla (ES6+)
* [PokéAPI](https://pokeapi.co/)

## 🇬🇧 English

### 📝 About the Project
**PokéWiki & Team Builder** is an interactive web application built for Pokémon trainers to browse encyclopedic data and build competitive or casual teams. The project fetches live data directly from the PokéAPI, covering all Pokémon up to the **9th Generation (Paldea)**.

### ✨ Key Features
* **Complete Encyclopedia (Generations 1 to 9):** Organized tab navigation covering all 1025+ Pokémon across all generations.
* **Search & Filter System:** Real-time search by Pokémon name or PokéDex number, combined with filtering options by Type and Generation.
* **Detail Modal (Wikipedia-Style):** Displays detailed base stats, typing, biological data, height, weight, and main abilities.
* **Team Builder:** Allows users to select up to 6 Pokémon to compose a custom team, saved locally via `localStorage`.
* **Tactical Analytics & Weakness Chart:**
  * **Defensive Vulnerability Chart:** Maps weaknesses, resistances, and immunities for the team against all 18 elemental types.
  * **Offensive Coverage (STAB):** Tracks which types your team can hit for super-effective damage.
  * **Strategic Insights:** Automatically provides feedback and alerts on team composition balance and defensive gaps.
* **Dynamic Theme Switcher:** Custom visual themes inspired by iconic Pokémon (*Pikachu Yellow*, *Umbreon Dark*, *Rotom Red*).

### 🛠️ Tech Stack
* HTML5 / CSS3 (CSS Variables & Grid Layout)
* Vanilla JavaScript (ES6+)
* [PokéAPI](https://pokeapi.co/)

## 🇷🇺 Русский

### 📝 О проекте
**PokéWiki & Team Builder** — это интерактивное веб-приложение, созданное для тренеров Pokémon, которое позволяет просматривать энциклопедические данные и собирать команды. Проект загружает актуальные данные напрямую из PokéAPI и охватывает всех покемонов вплоть до **9-го поколения (Палдея)**.

### ✨ Основные возможности
* **Полная энциклопедия (1–9 поколения):** Удобная навигация по вкладкам поколений, охватывающая более 1025 покемонов.
* **Поиск и фильтрация:** Поиск в реальном времени по имени или номеру в Pokédex, а также фильтрация по типам и поколениям.
* **Подробная карточка (в стиле Википедии):** Отображение базовых характеристик, типов, биологического описания, роста, веса и основных способностей.
* **Конструктор команды (Team Builder):** Возможность собрать команду до 6 покемонов с сохранением данных в `localStorage`.
* **Тактический анализ и график уязвимостей:**
  * **График защитных уязвимостей:** Отображение слабостей, сопротивлений и иммунитетов команды ко всем 18 типам.
  * **Атакующее покрытие (STAB):** Анализ типов, которым команда может наносить суперэффективный урон.
  * **Стратегический диагноз:** Автоматические рекомендации и предупреждения о балансе и слабых местах состава.
* **Смена тем оформления:** Переключение визуальных тем, вдохновленных покемонами (*Пикачу*, *Амбреон*, *Ротом*).

### 🛠️ Технологический стек
* HTML5 / CSS3 (CSS-переменные и Grid Layout)
* Чистый JavaScript (ES6+)
* [PokéAPI](https://pokeapi.co/)
